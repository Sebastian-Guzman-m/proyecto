# Catálogo de iconos

Los iconos SVG se usan en botones, navegación, fichas y marcadores. Los nombres de color indican una variante visual. Los iconos que los scripts crean al vuelo se cargan desde esta misma carpeta.

## Mapa y ubicación

| Archivo | Uso |
| --- | --- |
| `pin-mapa.svg` | Marcador fijo de un plan en el mapa. |
| `pin-seleccion.svg` | Marcador temporal del punto que se está eligiendo. |
| `marcador-mapa.svg` | Símbolo de la sección Mapa. |
| `marcador-mapa-amarillo.svg` | Símbolo de Mapa cuando la sección está activa. |
| `marcador-mapa-cian.svg` | Símbolo de ubicación en la ficha y el chat. |

## Planes y actividad

| Archivo | Uso |
| --- | --- |
| `destello.svg` | Icono general de plan. |
| `destello-amarillo.svg` | Plan deportivo o de fútbol. |
| `destello-rosa.svg` | Plan de lectura o cultura. |
| `destello-cian.svg` | Plan de bici o actividad al aire libre. |
| `futbol.svg` | Balón en el mensaje de ejemplo. |
| `reloj.svg` | Fecha u horario en una tarjeta y en la navegación. |
| `reloj-cian.svg` | Fecha y hora en el detalle del plan. |
| `reloj-amarillo.svg` | Sección Mis planes activa. |
| `estrella.svg` | Acción visual Guardar plan. |
| `estrella-amarillo.svg` | Marca del anfitrión en el chat de ejemplo. |

## Navegación, chat y controles

| Archivo | Uso |
| --- | --- |
| `nexo.svg` | Logotipo de Nexo. |
| `burbuja-mensaje.svg` | Enlace a Mensajes. |
| `burbuja-mensaje-amarillo.svg` | Enlace a Mensajes cuando está activo. |
| `mas-oscuro.svg` | Símbolo para crear un pin o plan. |
| `cerrar.svg` | Cerrar la ficha del plan. |
| `flecha-arriba-oscuro.svg` | Enviar un mensaje. |
| `flecha-abajo.svg` | Flecha hacia abajo; no está enlazada desde la interfaz actual. |
| `flecha-derecha.svg` | Avanzar o abrir una tarjeta. |
| `flecha-derecha-cian.svg` | Enlace para ir a otra lista. |
| `flecha-derecha-oscuro.svg` | Flecha de los botones principales. |
| `flecha-izquierda.svg` | Volver desde el detalle. |
| `flecha-izquierda-cian.svg` | Volver desde los ajustes. |
| `marca-verificacion-oscuro.svg` | Marca de verificación de una casilla. |
| `circulo-punto-amarillo.svg` | Indicador de visibilidad del pin. |

## Licencias

- `LICENCIA-LUCIDE.txt` contiene los términos y atribuciones de los iconos Lucide y de los iconos derivados de Feather indicados allí.
- `LICENCIA-TWEMOJI.txt` contiene la licencia del arte de Twemoji usado en los recursos correspondientes.

Conserva estos archivos de licencia si copias o distribuyes los iconos. Para saber qué SVG está enlazado en una pantalla, busca su nombre en `index.html`, `css/styles.css` y `javascript/`.
